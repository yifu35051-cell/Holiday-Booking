当前使用 WireMock + DirectMail，不再要求 Mailpit。源码或迁移变化后主动构建一次，普通启动只运行已准备好的镜像/JAR。出现 `No such image` 时准备缺少的对应镜像，不能用 MySQL/Mailpit 基础镜像代替项目后端镜像。

浏览器可见前端 HTML/JS 属于 Web 正常机制；部署应提供打包产物、关闭 source map，并将秘密和权限校验留在服务端。查看私人 API 显示“请先登录”属于会话鉴权；隔离 Java 测试自行启动 Spring 上下文，不使用已运行的后端。
